=== Wolfi/Chainguard package advisories (samples/wolfi_openssl.advisories.yaml) ===
Format: Chainguard 'secfixes/advisories' YAML (schema-version 2.0.2),
NOT raw OpenVEX. One file per PACKAGE (not per image, not per CVE),
containing every advisory (CVE) ever filed against that package across
all its historical versions. OpenVEX is generated on-demand from this
data by `wolfictl advisory` tooling -- it is not published as a static
OpenVEX feed.

=== Wolfi aggregate security.json (samples/wolfi_security.json) ===
packages_in_file=1449
Shape: ONE file for the entire Wolfi repo, containing every package,
each with a secfixes map keyed by package version -> list of CVE/GHSA ids.
This is the opposite extreme from Red Hat: Red Hat = 1 file per CVE across
all products; Wolfi = 1 file for the whole distro across all packages.
